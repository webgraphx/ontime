افزونه سبک‌وزن، امن و آماده انتشار در ژاکت و راستچین برای رزرو و مدیریت نوبت آنلاین با پشتیبانی کامل تقویم جلالی.

== Description ==

OnTime یک سیستم رزرو و مدیریت نوبت آنلاین برای وردپرس است که با تمرکز بر سبک بودن، امنیت بالا و سازگاری با استانداردهای وردپرس ساخته شده است. این افزونه برای انتشار در مارکت‌های ایرانی ژاکت و راستچین بهینه شده است.

= ویژگی‌ها =

* تقویم جلالی کامل — تمام محاسبات زمانی در UTC انجام و تنها در لایه نمایش به جلالی تبدیل می‌شود تا از انحراف منطقه‌زمانی جلوگیری شود.
* محاسبه خودکار اسلات‌های آزاد ۳۰ دقیقه‌ای بر اساس ساعات کاری کارشناس و نوبت‌های موجود.
* پشتیبانی از تعطیلات رسمی ایران (قابل فیلتر).
* پنل مدیریت حرفه‌ای با Settings API و جدول نوبت‌ها (WP_List_Table) شامل عملیات گروهی، جستجو و فیلتر.
* فرم رزرو گام‌به‌گام، موبایل‌محور و سریع با JavaScript خالص و CSS سبک‌وزن (بدون jQuery).
* لایه انتزاعی پرداخت با درگاه شبیه‌سازی برای توسعه و درگاه مرجع زرین‌پال.
* تأیید کامل nonce، پاک‌سازی ورودی و خروجی، و کوئری‌های آماده با `$wpdb->prepare()`.
* تمام رشته‌ها بین‌المللی‌سازی شده با text domain «ontime».

== Installation ==

1. پوشه `ontime` را در مسیر `wp-content/plugins/` کپی کنید.
2. از منوی افزونه‌ها، OnTime را فعال کنید (جداول سفارشی هنگام فعال‌سازی ساخته می‌شوند).
3. به منوی OnTime → تنظیمات بروید و درگاه پرداخت و قوانین رزرو را پیکربندی کنید.
4. شورت‌کد `[ontime_booking_form]` را در هر برگه یا نوشته قرار دهید.
5. در صورت تغییر قوانین rewrite، پیوندهای یکتا را از بخش تنظیمات وردپرس یک‌بار بازنویسی کنید.

== Testing checklist (چک‌لیست تست) ==

* فعال‌سازی بدون خطا یا notice با WP_DEBUG = true.
* ساخته شدن سه جدول سفارشی پس از فعال‌سازی.
* نمایش صحیح تاریخ‌های جلالی در جدول مدیریت و فرم.
* محاسبه اسلات‌های آزاد با رعایت ساعات کاری و تعطیلات.
* تأیید nonce و پاک‌سازی در تمام اندپوینت‌های AJAX.
* عملیات گروهی، جستجو و فیلتر در جدول نوبت‌ها.
* عملکرد کامل مسیر پرداخت شبیه‌سازی.

== Frequently Asked Questions ==

= آیا داده‌ها هنگام حذف افزونه پاک می‌شوند؟ =
خیر؛ به‌صورت پیش‌فرض جداول و نوبت‌ها حفظ می‌شوند. برای پاک‌سازی کامل، ثابت `ONTIME_PURGE_ALL` را در `wp-config.php` تعریف کنید.

= آیا نیاز به jQuery است؟ =
خیر؛ فرم با JavaScript خالص کار می‌کند.
