# چک‌لیست نصب و تست افزونه OnTime

## 📋 چک‌لیست قبل از انتشار

### ✅ بررسی‌های کد

- [x] تمام رشته‌های قابل نمایش کاربر با توابع ترجمه (`__()`, `_e()`, `esc_html__()`) پوشانده شده‌اند
- [x] text domain `ontime` برای تمام رشته‌ها مشخص شده است
- [x] تمام کوئری‌های پایگاه داده از `$wpdb->prepare()` استفاده می‌کنند
- [x] تمام ورودی‌ها قبل از ذخیره در پایگاه داده پاک‌سازی شده‌اند:
  - `sanitize_text_field()` برای فیلدهای متنی
  - `sanitize_email()` برای ایمیل‌ها
  - `absint()` برای شناسه‌ها
  - `sanitize_textarea_field()` برای متن‌ها
- [x] تمام خروجی‌ها با توابع مناسب امن‌سازی شده‌اند:
  - `esc_html__()` / `esc_html_e()` برای HTML
  - `esc_attr()` برای خصوصیت‌ها
  - `esc_url()` برای URL‌ها
  - `wp_json_encode()` برای JSON
- [x] هیچ خروجی به صورت مستقیم (echo/print) بدون امن‌سازی وجود ندارد
- [x] تمام nonce‌ها با `wp_create_nonce()` و `wp_verify_nonce()` / `check_ajax_referer()` بررسی می‌شوند
- [x] هیچ warning یا notice‌ای در حالت WP_DEBUG نمایش داده نمی‌شود
- [x] تمام کلاس‌ها از الگو Singleton استفاده می‌کنند (کде بهتر است)
- [x] تمام فایل‌ها دارای هدر مناسب هستند

### ✅ بررسی‌های امنیتی

- [x] CSRF protection برای تمام فرم‌ها و AJAX requests
- [x] Sanitization و Validation برای تمام ورودی‌ها
- [x] Output Escaping برای تمام خروجی‌ها
- [x] استفاده از prepared statements برای تمام کوئری‌های پایگاه داده
- [x] حفاظت از XSS در تمام مقادیر نمایش داده شده
- [x] حفاظت از SQL Injection در تمام کوئری‌ها
- [x] بررسی privileges در سامانه مدیریت
- [x] استفاده از HTTPS برای درگاه‌های پرداخت

### ✅ بررسی‌های عملکردی

- [x] تمام شورت‌کدها کار می‌کنند
- [x] فرم رزرو چندمرحله‌ای به درستی کار می‌کند

## 🚀 چک‌لیست نصب

### مرحله 1: نصب افزونه

- [ ] فایل ZIP افزونه را دانلود کنید
- [ ] در پیشخوان وردپرس به "افزونه‌ها > افزودن" بروید
- [ ] روی "بارگذاری افزونه" کلیک کنید
- [ ] فایل ZIP را انتخاب و بارگذاری کنید
- [ ] روی "نصب و فعال‌سازی" کلیک کنید

### مرحله 2: تنظیمات اولیه

- [ ] به "OnTime > تنظیمات" بروید
- [ ] نام کسب و کار را وارد کنید
- [ ] شماره تلفن و آدرس را وارد کنید
- [ ] تنظیمات پایه را ذخیره کنید

### مرحله 3: تعریف سرویس‌ها

- [ ] به "OnTime > سرویس‌ها" بروید
- [ ] سرویس‌های خود را اضافه کنید
- [ ] مدت زمان و قیمت هر سرویس را تعیین کنید
- [ ] سرویس‌ها را فعال کنید

### مرحله 4: تعریف پرسنل

- [ ] به "OnTime > پرسنل" بروید
- [ ] پرسنل را اضافه کنید
- [ ] ساعت‌های کاری هر پرسنل را تنظیم کنید
- [ ] پرسنل‌ها را فعال کنید

### مرحله 5: تنظیم درگاه پرداخت (اختیاری)

- [ ] به "OnTime > پرداخت‌ها" بروید
- [ ] درگاه پرداخت مورد نظر را انتخاب کنید
- [ ] اطلاعات درگاه (مرچنت کد، کلید، و...) را وارد کنید
- [ ] درگاه را فعال کنید

### مرحله 6: ایجاد صفحه رزرو

- [ ] یک صفحه جدید ایجاد کنید (مثلاً "رزرو نوبت")
- [ ] شورت‌کد `[ontime_booking_form]` را اضافه کنید
- [ ] صفحه را منتشر کنید
