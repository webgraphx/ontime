سیستم نوبت‌دهی و رزرو آنلاین سبک‌وزن و امن با پشتیبانی کامل از تقویم جلالی، مناسب بازار ایرانی.

== Description ==

OnTime یک افزونه وردپرسی سبک‌وزن و امن برای مدیریت نوبت‌دهی آنلاین است. این افزونه با پشتیبانی کامل از تقویم جلالی، منطبق با نیازهای بازار ایرانی طراحی شده و آماده انتشار در ژاکت و راستچین است.

ویژگی‌های کلیدی:

* پشتیبانی کامل از تقویم جلالی و اعداد فارسی
* ذخیره‌سازی زمان به‌صورت UTC (امن و بین‌المللی)
* جدول‌های سفارشی دیتابیس برای کارایی بالا
* فرم رزرو موبایل‌محور چندمرحله‌ای
* پنل مدیریت کامل با جستجو، فیلتر و عملیات گروهی
* پشتیبانی از درگاه‌های پرداخت ایرانی
* کد سبک‌وزن بدون وابستگی به کتابخانه سنگین

== Installation ==

1. فایل zip افزونه را در مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» آپلود کنید.
2. افزونه را فعال کنید.
3. از منوی OnTime در پیشخوان وردپرس تنظیمات را انجام دهید.
4. با شورت‌کد [ontime_booking_form] فرم رزرو را در هر صفحه یا نوشته نمایش دهید.

== Frequently Asked Questions ==

= آیا این افزونه تقویم جلالی را پشتیبانی می‌کند؟ =

بله، تقویم جلالی به‌صورت کامل پشتیبانی می‌شود. تمام زمان‌ها به‌صورت UTC ذخیره و فقط در لایه نمایش به جلالی تبدیل می‌شوند.

= آیا برای استفاده به افزونه دیگری نیاز است؟ =

خیر، OnTime مستقل است و به هیچ افزونه دیگری وابستگی ندارد.
