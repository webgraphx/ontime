سیستم حرفه‌ای رزرو و مدیریت نوبت آنلاین با پشتیبانی کامل از تقویم شمسی (جلالی) و درگاه‌های پرداخت ایرانی.

== توضیحات ==

OnTime یک افزونه وردپرس برای ایجاد سیستم رزرو نوبت آنلاین است که به صورت کامل با نیازهای کسب و کارهای ایرانی طراحی شده است. این افزونه از تقویم جلالی (شمسی) پشتیبانی می‌کند و امکان مدیریت کامل نوبت‌ها، سرویس‌ها، پرسنل و پرداخت‌های آنلاین را فراهم می‌سازد.

== ویژگی‌ها ==

* **تقویم جلالی کامل**: پشتیبانی کامل از تقویم شمسی با تبدیل خودکار تاریخ‌ها
* **سیستم رزرو چندمرحله‌ای**: تجربه کاربری مدرن و موبایل‌اول برای رزرو آنلاین
* **مدیریت سرویس‌ها و پرسنل**: تعریف نامحدود سرویس، کارشناس و ساعت‌های کاری
* **درگاه‌های پرداخت ایرانی**: پشتیبانی از درگاه‌های پرداختی مانند زرین‌پال، ملت، پی و سایر درگاه‌ها
* **مدیریت زمان**: تعیین ساعت‌های کاری، تعطیلات رسمی ایرانی و مدیریت مناسبات
* **تایید و اعلان‌ها**: ارسال ایمیل و پیامک تاییدیه به مشتریان (با پشتیبانی از افزونه‌های پیامک ایرانی)
* **داشبورد مدیریت**: مشاهده آمار، گزارش‌ها و مدیریت کامل نوبت‌ها
* **جستجوی پیشرفته**: جستجوی نوبت‌ها بر اساس تاریخ، سرویس، پرسنل و وضعیت
* **ویجت‌ها و شورت‌کدها**: نمایش فرم رزرو در هر جای سایت با شورت‌کد
* **پشتیبانی از RTL**: طراحی کامل راست‌چین برای زبان فارسی

== نصب ==

1. فایل ZIP افزونه را از مخزن دانلود کنید
2. در پیشخوان وردپرس به منوی "افزونه‌ها > افزودن" بروید
3. روی "بارگذاری افزونه" کلیک کنید و فایل ZIP را انتخاب کنید
4. پس از بارگذاری روی "نصب و فعال‌سازی" کلیک کنید
5. پس از فعال‌سازی، منوی "OnTime" در پیشخوان وردپرس ظاهر خواهد شد

== تنظیمات اولیه ==

پس از نصب:

1. به منوی "OnTime > تنظیمات" بروید
2. اطلاعات پایه نظیر نام کسب و کار، شماره تلفن و آدرس را وارد کنید
3. سرویس‌های خود را در "OnTime > سرویس‌ها" تعریف کنید
4. پرسنل و ساعت‌های کاری آنها را در "OnTime > پرسنل" تعریف کنید
5. در صورت نیاز درگاه پرداخت را در "OnTime > پرداخت‌ها" تنظیم کنید

== شورت‌کدها ==

* `[ontime_booking_form]` - فرم رزرو چندمرحله‌ای
* `[ontime_booking_form title="عنوان سفارشی"]` - فرم با عنوان سفارشی
* `[ontime_booking_form service_id="5"]` - فرم با سرویس پیش‌فرض
* `[ontime_booking_form staff_id="3"]` - فرم با پرسنل پیش‌فرض
* `[ontime_booking_form service_id="5" staff_id="3" title="رزرو تخصصی"]` - فرم با تنظیمات سفارشی

== فیلترها و اکشن‌ها ==

* `ontime_appointment_confirmed` - پس از تایید نوبت فعال می‌شود
* `ontime_payment_completed` - پس از پرداخت موفق فعال می‌شود
* `ontime_iranian_holidays` - برای اضافه کردن تعطیلات سفارشی
* `ontime_payment_providers` - برای اضافه کردن درگاه‌های پرداخت سفارشی

== ادبیات (Text Domain) ==

این افزونه از text domain `ontime` استفاده می‌کند و برای ترجمه کامل آماده است.

== نکات امنیتی ==

* تمام درخواست‌های AJAX با nonce محافظت می‌شوند
* تمام ورودی‌ها قبل از ذخیره در پایگاه داده پاک‌سازی می‌شوند
* تمام خروجی‌ها برای جلوگیری از حملات XSS امن‌سازی می‌شوند
* پرداخت‌ها با استفاده از درگاه‌های معتبر ایرانی انجام می‌شوند

== پرسش‌های متداول ==

= آیا این افزونه رایگان است؟ =
بله، نسخه پایه افزونه به صورت رایگان ارائه می‌شود. برای دسترسی به ویژگی‌های پیشرفته‌تر می‌توانید نسخه حرفه‌ای را خریداری کنید.

= آیا از تقویم جلالی پشتیبانی می‌کند؟ =
بله، تمام تاریخ‌ها به صورت خودکار به تقویم جلالی تبدیل می‌شوند و کاربر نهایی تنها تاریخ‌های شمسی را مشاهده می‌کند.

= چگونه می‌توانم درگاه پرداخت را تنظیم کنم؟ =
به منوی "OnTime > پرداخت‌ها" بروید و درگاه مورد نظر خود را انتخاب و تنظیم کنید. در حال حاضر درگاه‌های زرین‌پال، ملت و پی پشتیبانی می‌شوند.

= آیا می‌توانم ساعت‌های کاری مختلف برای هر پرسنل تعریف کنم؟ =
بله، برای هر پرسنل می‌توانید ساعت‌های کاری متفاوتی در روزهای مختلف هفته تعریف کنید.

= چگونه می‌توانم نوبت‌ها را مدیریت کنم؟ =
تمام نوبت‌ها در منوی "OnTime > نوبت‌ها" قابل مشاهده و مدیریت هستند. می‌توانید نوبت‌ها را جستجو، فیلتر و وضعیت آنها را تغییر دهید.

= آیا افزونه از چند زبانه پشتیبانی می‌کند؟ =
بله، افزونه با افزونه‌های چندزبانه مانند WPML سازگار است و از text domain `ontime` برای ترجمه‌ها استفاده می‌کند.

= چگونه می‌توانم فرم رزرو را سفارشی کنم؟ =
فرم رزرو با استفاده از CSS سفارشی‌سازی شده است. می‌توانید از طریق متغیرهای CSS یا افزودن CSS سفارشی ظاهری فرم را تغییر دهید.

== توسعه‌دهندگان ==

اگر قصد توسعه افزونه را دارید:

1. از Git مخزن را clone کنید
2. کامپوزر را نصب کنید: `composer install`
3. فایل‌های PHP را مطابق PSR-4 سازماندهی کنید
4. برای اضافه کردن درگاه پرداخت سفارشی، از اینترفیس `OnTime\Payment\Payment_Provider_Interface` استفاده کنید
